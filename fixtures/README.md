# Test fixtures

Generated by `npm run fixtures` (`scripts/make-fixtures.mjs`). All text was written for
this project; no books or personal documents are included, so the repo can be public.

| File | How it is made |
|---|---|
| `arabic-book.pdf` | `src/arabic-book.html` printed with headless Chrome/Edge (`--print-to-pdf --generate-pdf-document-outline`). 12 A5 pages, Arial, right-to-left, chapters on pages 1/4/7/10 → 4-entry outline. Chrome writes Arabic as presentation-form glyphs in visual order, the hard real-world case the reader's text extraction must handle. |
| `arabic-book.source.txt` | The body paragraphs of page 1, one per line, exactly as written in the HTML. |
| `english-two-column.pdf` | `src/english-two-column.html` printed the same way. 3 A4 pages, two columns; the word `lighthouse` appears once on each page. |
| `scanned.pdf` | Two headless-browser screenshots (PNG) embedded as full-page images with pdf-lib. No text operators. |
| `password.pdf` | Two pages made with `@cantoo/pdf-lib`, encrypted with user password `test123` (owner `owner123`). |
| `not-a-pdf.pdf` | The bytes `hello, I am not a pdf`. |
| `truncated.pdf` | The first 40% of the bytes of `english-two-column.pdf`. |

`src/fonts/` holds Amiri (SIL Open Font License 1.1, from `@fontsource/amiri`) for future fixtures.

- `office/sample-lo.pdf`: `office/sample.docx` converted by LibreOffice 26.2.7 (`soffice --convert-to pdf`). Real-world Arabic PDF: lam-alef ligatures, Arabic inside an English line, a number table.
